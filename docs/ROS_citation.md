# Citation and Attribution

## Dataset scope

This release contains raw plate images and derived single-worm or processing
images from a natural-compound screen using a mitochondrial HyPer2 reporter in
*C. elegans*. The metadata workbook and compound
reference table accompany the images as documentation.

## Dataset citation draft

```text
<Creator(s)> (<Year>). C. elegans HyPer2 Natural-Compound Screening Image
Dataset (Version <version>). <Repository>. <Dataset DOI>.
```

When citing an individual image, include its `CE_ROS_SCREEN_######` identifier
and `relative_path` from [`metadata/metadata.xlsx`](metadata/ROS_metadata.xlsx).

## BibTeX draft

```bibtex
@dataset{CreatorYearCelegansHyPer2Screen,
  author    = {<Creator names>},
  title     = {C. elegans HyPer2 Natural-Compound Screening Image Dataset},
  year      = {<Year>},
  publisher = {<Repository>},
  version   = {<Version>},
  doi       = {<Dataset DOI>},
  url       = {<Dataset URL>}
}
```

## Related publication

If this dataset is linked to a dissertation, article, or other formal research
output, add its complete citation and persistent identifier here:

```text
<Author(s)>. <Title>. <Publication or institution>, <Year>.
<DOI or stable repository URL>.
```
